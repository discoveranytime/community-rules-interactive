# Community Rules — Interactive Infographic

A click-to-expand, single-page infographic of the community rules: 12 rules grouped into 4 themed sections (Learn the right way, Ask well, No selling no spam, Respect & responsibility).

- Live search-free interactive layout: expand/collapse accordions, expand-all / collapse-all, and a read-progress counter
- Subtle animated dot backdrop (disabled under `prefers-reduced-motion`)
- Fully self-contained `index.html` — no build step, no external assets

View it live: https://discoveranytime.github.io/community-rules-interactive/
